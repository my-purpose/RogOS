## 问题记录

### A-01：联系人立即刷新可能丢失（高优先级）

复现：新建联系人 → 输入姓/名 → Done → 立即刷新。曾观察到名称回退以及新记录消失；等待约一秒后刷新则保留。源码的 IndexedDB 持久化采用延迟写入，pagehide 提交是异步的 best effort；这与症状一致，但不是完整根因证明。未修复业务代码。

可重复运行：

```sh
CHROME_PATH='/Applications/Google Chrome.app/Contents/MacOS/Google Chrome' node scripts/acceptance/contacts-reload.mjs
```

脚本创建隔离上下文，不碰日常数据；5 轮立即刷新加 1 轮等待对照，观察到任何丢失则退出码 1。一次全部通过不能排除时序风险。2026-11-19 重复运行结果：5 次立即刷新全部丢失，等待 1000ms 的对照保留，见 `contacts-reload-repeat.json`。

### A-02：Books 全量测试出现高亮颜色差异（待定位）

`test-books-highlight-default-color.test.tsx` 的 settled selection 用例在全量运行中失败，单独运行 11/11 通过。尚未证明是产品缺陷或测试间干扰。保留失败日志节选，不能把隔离运行通过等同于全量修复。
